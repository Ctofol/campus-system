# 隐私与数据处理说明（上线前模板）

本文件供学校、运营方和开发者确认数据处理边界；正式上架前应由实际运营主体补全联系人、保存期限和投诉渠道。

## 数据类型与用途

| 数据 | 用途 | 建议访问范围 |
| --- | --- | --- |
| 姓名、学号、手机号、班级 | 账号、任务与班级管理 | 本人、授权教师、管理员 |
| 跑步轨迹与运动数据 | 跑步记录、阳光跑达标判断 | 本人、授权教师、管理员 |
| 体测视频 | AI 分析、教师复核、成绩依据 | 本人、授权教师、管理员 |
| 人脸照片与特征 | 身份核验、防替跑 | 本人、授权审核人员、系统服务 |

## 上线前必须明确的事项

1. 在人脸建档和视频上传前展示用途说明，并获取用户明确同意。
2. 说明每类数据的保存期限，例如体测视频保存到学期结束后 90 天。
3. 指定数据删除、账号注销和人工申诉的受理渠道。
4. 审计日志不得记录密码、Token、人脸 embedding 或完整隐私附件链接。
5. 仅授权角色可访问学生数据；管理员访问敏感数据应可追溯。

## 当前系统提供的支持

- 人脸与视频文件使用随机文件名保存。
- 管理员和教师关键操作写入审计记录。
- 上传文件可通过 `backend/scripts/report_upload_usage.py` 只读盘点。

## 待运营方决定

- 各类数据的最终保留期限。
- 是否允许学生主动删除人脸档案与历史视频。
- 是否使用对象存储和独立密钥管理服务。
