# 上架材料准备清单

本清单只覆盖材料准备，不替代应用商店、学校或运营主体的实际审核要求。

## 基础信息

- [ ] 应用名称、简介、版本号和运营主体名称一致。
- [ ] 准备应用图标、启动页和至少 5 张真实功能截图。
- [ ] 准备测试账号：管理员、教师、学生各 1 个；不得使用真实学生信息。
- [ ] 撰写本次版本更新说明，明确新增、修复和已知限制。

## 隐私与合规

- [ ] 发布隐私政策链接，明确运营主体、联系方式、投诉渠道和生效日期。
- [ ] 发布用户协议或学校使用规则。
- [ ] 对手机号、定位、相册/相机、体测视频、人脸核验分别说明用途。
- [ ] 明确数据保存期限、删除申请和账号注销的处理方式。
- [ ] 在真机上核对权限申请文案与实际功能一致。

## 审核与验收

- [ ] 提供审核人员可复现的登录路径和测试步骤。
- [ ] 逐项完成[发布检查清单](release-checklist.md)。
- [ ] 真机验证登录、定位、上传、人脸核验和后台审核。
- [ ] 保存发布包、数据库迁移版本、上传目录盘点和备份记录。

## 需运营方确认的内容

- 隐私政策与用户协议的最终正文。
- 运营主体联系人、客服电话或邮箱。
- 人脸照片、特征、视频与轨迹的最终保存期限。
- 上架的平台、类目、审核账号和发布节奏。
