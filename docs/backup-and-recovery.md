# 备份与恢复演练

## 备份范围

每日至少备份两类内容：

1. PostgreSQL 数据库（或生产实际使用的数据库）。
2. 后端 `uploads/` 目录，其中包含视频、照片和头像。

数据库与文件必须使用同一日期标记，例如 `campus_2026-07-29.sql.gz` 和 `uploads_2026-07-29.tar.gz`。

## 恢复演练

上线前应在非生产环境完成一次：

1. 新建空数据库和空上传目录。
2. 恢复一份数据库备份。
3. 恢复同日期上传文件备份。
4. 执行 `python -m alembic upgrade head`。
5. 启动服务并访问 `/system/health`。
6. 使用测试账号登录，检查头像、视频和历史运动记录。

## 验收标准

- 数据库可连接，迁移版本为最新。
- 上传文件能正常显示。
- 学生、教师、管理员可分别登录。
- 不使用生产密码、Token 或真实学生信息作为演练截图材料。

## 注意

恢复操作会覆盖目标数据库；必须在确认目标是演练环境后执行。生产恢复需要由负责人确认备份日期和影响范围。
