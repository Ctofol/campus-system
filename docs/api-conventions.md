# API 约定

本文约束新增和重构接口；为避免影响现有客户端，本轮不批量改变已有响应。

## 基本规则

- 路径使用小写、短横线或现有稳定前缀，已有路径不得静默修改。
- 认证使用 `Authorization: Bearer <token>`。
- 时间对外使用带时区的 ISO 8601；历史接口格式在版本化迁移前保持不变。
- `400` 表示请求语义无效，`401` 表示未登录，`403` 表示无权限，`404` 表示资源不存在，`409` 表示状态冲突，`422` 表示参数校验失败。
- 列表接口新增时统一支持 `page`、`page_size`，并设置最大页大小。

## 错误结构目标

新接口优先使用稳定错误码：

```json
{
  "code": "FACE_QUALITY_TOO_LOW",
  "message": "照片质量不足",
  "details": {}
}
```

现有接口仍依赖 FastAPI 的 `detail` 字段，不在本轮改变。后续迁移必须先让前端兼容两种结构，再逐个接口切换。

## 兼容性

- 删除字段、重命名字段、改变类型或状态码均视为破坏性变更。
- OpenAPI 路径快照和接口测试用于验证路由拆分前后兼容。
- 静态资源 URL 不拼入 `/api` 前缀，继续由前端 `resolveMediaUrl` 处理。
