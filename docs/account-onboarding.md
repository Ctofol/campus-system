# 学校账号开通与首次设置

## 管理员如何开通账号

学校账号不支持学生或教师自行注册。管理员可在管理端“用户管理”中单个新增，也可在“批量导入”中按模板导入。

- 学生至少需要真实姓名、学号；可选填班级，手机号由学生首次登录时绑定。
- 教师至少需要真实姓名、工号；手机号可预先填写，也可由教师首次登录时绑定。
- 新账号使用服务器配置的统一初始密码 `INITIAL_ACCOUNT_PASSWORD`，管理端不展示密码内容。
- 学号、工号和已绑定手机号均不可与其他账号重复。

## 用户首次登录

用户使用学号、工号或已绑定手机号加统一初始密码登录。新账号只能进入首次设置页，并依次完成：

1. 核对档案真实姓名；姓名不一致时联系管理员修正。
2. 绑定本人唯一手机号。
3. 设置 8–20 位、同时包含字母和数字的新密码。
4. 可选设置昵称；昵称用于个人中心、跑团等社交展示，真实姓名继续用于教学和管理记录。

完成后旧的首次设置令牌立即失效，用户使用新密码重新进入正常账号状态。

## 后续账号安全

- 修改密码必须验证当前密码；成功后所有旧登录令牌失效，需要重新登录。
- 修改手机号必须验证当前密码，新手机号必须唯一。
- 真实姓名和手机号不能在普通资料编辑页直接修改。
- 管理员重置密码后，账号恢复为“待首次完善”，现有登录令牌失效，用户需按首次设置流程重新确认。

## 管理员日常检查

- 用户列表中的“待首次完善”表示账号尚未完成首次设置或刚被重置。
- 新增、批量导入、重置密码和用户完成首次设置会写入操作记录。
- 若用户忘记密码，由管理员执行“重置密码”，不要通过聊天或表格发送用户的新自定义密码。
